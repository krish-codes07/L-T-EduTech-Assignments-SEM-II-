# CT&DT-Galgotias-BatchNo5-Task1-ProductFailureAnalysis

## Task Name

Product Failure Analysis

## Topic

Machine Failure Analysis

## Objective

The objective of this task is to analyze machine failure data and identify the factors that may lead to product failure. By studying various machine parameters, it becomes possible to understand the causes of failure and suggest preventive measures.

## Product Identified

Industrial Manufacturing Machine

## Features Analyzed

1. **Air Temperature**

   * Represents the surrounding temperature of the machine.
   * High temperatures may increase the risk of overheating.

2. **Process Temperature**

   * Indicates the operating temperature during machine operation.
   * Excessive process temperature can damage machine components.

3. **Rotational Speed (RPM)**

   * Measures the speed of machine rotation.
   * Abnormal speeds can affect machine performance and reliability.

4. **Torque**

   * Represents the rotational force generated by the machine.
   * High torque may cause excessive mechanical stress.

5. **Tool Wear**

   * Indicates the amount of wear on machine tools.
   * Increased tool wear can reduce efficiency and increase failure probability.

## Observations

* Machines operating at high temperatures are more likely to fail.
* Excessive torque increases stress on machine components.
* High tool wear is strongly associated with machine failure.
* Improper rotational speed can negatively impact machine performance.

## Conclusion

Machine failure is influenced by multiple operational parameters such as temperature, torque, rotational speed, and tool wear. Regular monitoring of these parameters and timely maintenance can significantly reduce machine failures and improve productivity.
